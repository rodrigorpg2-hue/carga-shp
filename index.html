⚙️ Configuración

Cómo preparar GitHub: crea un repositorio privado (puede estar vacío con un README) → en GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → limita el token solo a ese repositorio con Contents: Read and write. Los registros se guardan en el JSON y cada foto como archivo en la carpeta de imágenes, cada uno como un commit.
